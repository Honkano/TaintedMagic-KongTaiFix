*   拔刀剑 (SlashBlade) —— *用于制作元始妖刃*

### ✨ 空太的魔改新增内容 (New Content)
1.  **原始妖刃（元始之刃拔刀剑）**：融合污秽魔法与拔刀剑机制的重型武器。
2.  **黄金暗影要塞套装**：高额防御，自带符文护盾与极高魔力减免。头盔专属魔导透镜效果（看节点）。
3.  **黄金暗影要塞之刃**：由暗影要塞之刃升级，攻击附带“超级削弱”与“反胃III”，支持铭刻。
4.  **永夜暗影深渊套 & 永夜深渊魔典（未测试版）**：提供创造飞行、极端护盾与变态级魔力减免，数值超模，谨慎使用。
5.  **配套魔导手册研究**：暗影套与暗影刀下方新增禁忌研究，解锁会获得扭曲值。

### ✨ KongTai's Additions
1.  **Primal Cursed Blade (SlashBlade)**: Combines Tainted Magic with SlashBlade mechanics.
2.  **Golden Shadow Fortress Armor**: High defense, built-in Runic Shield, Vis discount. Helmet grants Goggles of Revealing effect.
3.  **Golden Shadow Fortress Katana**: Upgraded from Shadow Metal Fortress Blade. Inflicts "Super Sapping" and Nausea III.
4.  **Fallen God Shadow Armor & Abyssal Tome (UNTESTED)**: Overpowered forbidden gear with Creative Flight, massive shields, and insane discounts.
5.  **Thaumonomicon Research**: New forbidden research entries below the Shadow Fortress set and Katana. Grants Warp upon unlocking.

### ⚠️ Notes
*   This branch contains heavily modded and potentially unbalanced content (e.g., "Golden" and "Eternal Night" sets).
*   Do NOT install this alongside the original Tainted Magic mod.
